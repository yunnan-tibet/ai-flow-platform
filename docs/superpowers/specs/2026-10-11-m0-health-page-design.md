# M0 前端健康状态联调设计

状态：用户已确认 Vite 开发代理 + 最小状态页，授权 Codex 实现前端；后端不修改。

## 范围

替换 Vite 初始页面；React/TypeScript 和 CSS，不新增路由、UI 库、状态库或业务模块。页面初始化检查一次，支持手动重新检查，无轮询。初版原生 fetch 已于 2026-10-11 经用户确认改为 Axios/XRequest + services/pages/layouts + CSS Modules（D-007）；接口、视觉与交互边界不变。

## 请求与契约

- 前端使用相对路径 `/api/health` 和 `/api/ready`，由 Vite 开发代理转发至 `http://127.0.0.1:8000`，不改写 `/api`。
- health=200 且 api=ok：API 存活检查成功。
- ready=200 且 api=ok/database=ok：数据库连接检查成功。
- ready=503 且 api=ok/database=unavailable：数据库不可用。
- 网络错误、超时、非预期状态或无效响应：API 请求失败/数据库未知；不能把任意 503 或代理错误当成数据库故障。
- 两个检查独立并发，每个请求设置 8 秒超时；取消过期请求和卸载请求，不展示过期结果。刷新期间显示检查中，不把旧状态当成新结果。
- TS 类型不代替运行时响应校验；不渲染未经检查的服务端错误或敏感内容。
- Vite 代理仅用于开发，生产必须另行配置 `/api` 转发。

## 页面

- 视觉：浅色工作台，深色文字、细线分隔、蓝色主操作，状态颜色同时配文字。
- 内容：FlowInsight AI 标识、系统状态标题、API/数据库两行检查状态、接口路径、HTTP 状态、最近检查时间、刷新按钮。
- 交互：初始化检查、手动刷新；按钮 hover/focus 反馈、检查中旋转图标；尊重 reduced-motion。适配手机，无装饰性卡片或虚构数据。

## 验收

- 请求逻辑测试覆盖成功、数据库不可用、网络错误、代理错误、无效响应、超时、取消与恢复。
- lint/build 通过；浏览器显示与响应一致，加载和手动刷新正常。
- 真实代理链路健康；浏览器故障场景可通过拦截响应验证，既有后端容器故障/恢复已有用户验收证据。
- 前端故障模拟不等于重复执行真实数据库故障；记录具体证据，不据此直接宣布 M0 整体验收完成。
