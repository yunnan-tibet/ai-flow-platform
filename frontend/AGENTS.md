# FlowInsight 前端工作约定

作用范围：本目录下的前端设计、实现、Debug 与 Review。

- 页面生成、组件拆分、目录组织与结构 Review 使用用户级 `creating-react-page` 通用 skill；从当前宿主的技能目录解析实际位置，读取主文件及所需引用，不写死个人安装路径。不可用时说明缺口，仍遵守本文件的项目约定。
- 保持页面 → 领域 services → 统一 XRequest 的依赖方向；页面不直接请求 HTTP，App 只负责应用组合，页面私有组件就近组织。详细约定只在 skill 引用中维护。
- 规范是目标，不代表 XRequest/services/alias 已存在。先核对真实代码和本项目 LEARNING_STATE；项目进度与学习规则留在项目指令中，不作为通用 skill 的必需输入。不因规范文件出现就自行整体重构。
- 仅执行用户本次任务。新依赖、后端契约变化需确认；Python/Workflow/Agent/MCP 核心实现仍由用户手敲。Review 只读，不自动修复。
- 保留无关修改，不自动提交、发布或停止用户服务。实施后报告实际验证结果，不能把规范创建等同于代码迁移完成。
